# Installation & Setup

### 1. Clone the repository

```bash
git clone "https://github.com/Nexoratech26/Nexora.git
```

### 2. Navigate to the Frontend

```bash
cd Frontend/my-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open:

```text
http://localhost:3000
```
